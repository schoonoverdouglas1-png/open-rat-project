# Natural File Extensions Ember Works With — The Best List

Built Nov 16, 2026, at Douglas's ask, counted live from his own files (the deliverables folder `~/workspace/your_files/`, the home core, and the working machinery). Counts are real, from this morning's scan.

## First, his question: why do the markdown files look so picturesque?
Yes — markdown makes pictures easy. A picture is its own file (`.png` / `.jpg`), and one line of markdown — `![words](file)` — places it right inside the page. The app then renders the whole file beautifully: headings, links, and pictures together. That's why they look the way they do when Ember shows them.
