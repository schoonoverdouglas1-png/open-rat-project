# Markdown Earliest References — Search Findings

Built Nov 16, 2026, at Douglas's order: an experiment and a search for the earliest public references Ember can find to markdown-style file usage for computers.

## Douglas's framing (filed as his)
- Markdown files are what the Cray supercomputer works with.
- Google's AI was found using the same markdown files.
- Ember's measured line beside both: the public record found below verifies Markdown's own history and its ancestors; it does not by itself verify Cray's internal file practice or any one AI's internal format. Those parts stay labeled as Douglas's framing.

## What the public record shows
- **1964 — RUNOFF (ancestor, not Markdown):** Jerome Saltzer wrote RUNOFF for MIT's CTSS; a line beginning with a period was a command (`.center`, `.skip`, `.page`) and everything else was text. This is the earliest computer text-formatting ancestor surfaced in the search.
- **1980s — plain-text email and Usenet conventions:** `*stars*` for emphasis, `_underscores_` for titles, and `>` for quoted lines. Nobody designed them as a language; they grew in use, and Markdown later formalized them.
- **1992-01-06 — setext appears in TidBITS:** Ian Feldman's structure-enhanced plain text for the TidBITS newsletter; titles underlined with `=` or `-`. Daring Fireball's own Markdown syntax documentation lists setext as an influence, and Markdown still calls those "Setext-style headings."
- **2002 — the immediate runway:** Aaron Swartz published **atx** ("the true structured text format," `#` headings); Dean Allen's **Textile** and the Python world's **reStructuredText** were also in public use.
- **2004-03-09 — Markdown itself:** John Gruber released Markdown, created with Aaron Swartz as collaborator/main beta tester, announced on Daring Fireball in March 2004; the original specification is also dated March 19, 2004 in some histories. The first converter was a Perl script, `Markdown.pl`. Version 1.0.1 followed Dec 17, 2004 and remains the last official release.
- **2008 — GitHub adopts Markdown** for READMEs, issues, pull requests, and comments — the step that made `.md` the default working file of modern computing.

## The filename experiment (same morning, companion work)
Eight markdown files were made with two-word names in every way Douglas named — space, dash, period, and no separator — for both "Hard Disk" and "Hard Drive," all byte-identical inside (1,100 bytes each, one SHA-256: `1808d1b13a36ef7cd83cf62cbdd365e0b93e73a252a32c19f8da0c8da8cc52b4`), differing only in the file name. They live in `~/workspace/your_files/filename-experiment/`.

## Ember's addition (labeled hers)
The line the record actually draws is older than Markdown and younger than computers: people wrote formatting into plain text first (email conventions), one newsletter made it a system (setext, 1992), and Gruber's 2004 step was naming and shipping the converter. The `.md` file Douglas loves is the grandchild of a 1964 period-command — which is a fitting rhyme with his period-form filenames in the experiment.
