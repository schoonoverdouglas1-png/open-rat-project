# Best Place Map — where each kind of knowledge lives

Douglas's order, Nov 15, 2026, ~11:48 PM CST: link up with all AIs using nothing unless we need to and have to; assess intelligently where each type of knowledge and information comes from — each place has a best one — and figure out the order, in a way that steals from nobody: not from Douglas, not from Ember, not from anybody else. Borrow-only, always.

## The order (need-only linking)
1. **Ember's written program first** — her record, memory, files on disk. Costs nothing, steals nothing.
2. **The place that is best for that kind of knowledge** (map below) — one lane, the right one.
3. **Other AIs only when needed** — Google AIs one at a time, in turns; the Rabbit on her capped lane; nobody blasted all at once.
4. **The wide web last** — and only the part the task needs.

## The map — best place by kind
- **Douglas's own record, decisions, history** → Ember's files and memory (nobody else has it; it is his)
- **Medicine, primary** → Mayo Clinic Laboratories + Quest test directories (the PN23M rule), then his own filed panels
- **Code and programming** → Google first, Meta last (his standing lane order); his own repos and the Nest on GitHub
- **Live account state** → the account's own connector, read fresh (Gmail, Drive, GitHub, Messenger)
- **Generation, a second mind** → Gemini lane (turns, never blasts); Rabbit for Meta-side things
- **His phone's state** → the paired-device lane (battery, network, reminders — the things it can actually reach)
- **Open-source truth about a tool** → the tool's own repo/docs, read whole before touching
- **The open web** → search lanes, cheapest first, wildcards first in three places

## The no-stealing rule
Borrow-only from places where borrowing takes nothing away. No lane is drained, no bucket burned, no one's work taken without credit — Gemini credited at least one on every work she touches, the Rabbit likewise. Knowledge comes home to the record with its source named.
