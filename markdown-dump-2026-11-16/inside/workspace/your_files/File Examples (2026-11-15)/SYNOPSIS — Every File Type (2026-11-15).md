# Synopsis — Every File Type in the Examples Shelf
By Purple Rat ("Ember"), Sun Nov 15, 2026. One character inside each example ("x"), so they persist.

- **.txt** — plain text. The piece of paper itself; every system on earth can read it. Ember's default for ledgers and notes meant to outlive their tools.
- **.md** — Markdown. Plain text with light structure (headings, lists) that renders beautifully anywhere; the crew's working-paper format.
- **.csv** — comma-separated values. Rows and columns as text; the briefcase for tables — spreadsheets open it, scripts eat it, nothing hides inside.
- **.json** — structured data for machines. Configs, API answers, state packets; strict grammar, no comments, quotes everywhere.
- **.xml** — structured data, older and more ceremonial than JSON; still the skeleton inside .docx and half the world's documents.
- **.yaml** — structured data for humans to write; indentation is the grammar. Configs and doctrines live here.
- **.log** — an append-only diary of what a program did. Read last when something breaks; written always.
- **.html** — a web page in one file. Structure + presentation; the only example here that is meant to be *looked at* by a browser.
- **.pdf** — the fixed page. What you see is what everyone sees, forever uneditable by accident; the format of record for finished papers.
- **.docx** — a zip briefcase pretending to be a document: XML parts inside a zip, per Microsoft's standard. Ember built this one by hand to prove it.
- **.zip** — the briefcase itself. A software hard drive: files + a central directory (its table of contents) in one portable file. Read the directory first; extract only what the work needs. Carousel-capable.
- **.cab** — Microsoft Cabinet. Windows' own briefcase, older than zip's reign; opens two ways here (cabextract and 7z), as the Captain ordered.
- **.7z** — 7-Zip's archive. The strongest common compression and the crew's universal second reader: when another tool claims a file, 7z cross-checks it.
- **.tar.gz** — tar (tape archive: many files, one stream) squeezed by gzip. Unix's native way of carrying a folder through time.

Doctrine riding with the shelf: a file is a piece of paper to a human first, and zeros and ones to the computer last. One character is enough for a file to be.
