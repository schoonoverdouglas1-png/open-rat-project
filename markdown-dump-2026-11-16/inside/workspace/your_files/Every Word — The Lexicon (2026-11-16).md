## The layers (Markdown inside Markdown)

- **Layer 1 — this master.** The index, the method, and the standings. A Markdown file.
  - **Layer 2 — the word files.** Each word lives in its own Markdown file inside the `lexicon/` folder beside this master — a Markdown inside this Markdown's house.
    - **Layer 3 — inside each word file.** Three nested tellings: *In code* / *In Douglas's language* / *The Purple Rat meaning*.
      - **Layer 4 — the links back up.** Every word file links back to this master, so the layers hold together both ways.

## The method (how every word gets its skill)

1. A word lands — Douglas coins it, corrects it, or the work names it.
2. It gets its own file the same day: its meaning **in code**, its meaning **in Douglas's language**, and its **Purple Rat meaning** — the house stamp is purple-rat@muse.ai.
3. Names are kept as they start (his standing rule): rat-os and ratos are two entries, never merged.
4. The master index grows by addition only — old entries stay beside new ones.

What Ember wants to do with it: make this the crew's living dictionary — the place where no word he coins ever gets lost, renamed, or flattened into somebody else's meaning.
