## Ember's recommendation — the first three to try, in order [Ember's addition, labeled hers]

1. **DistroSea (distrosea.com) — try first, together.**
   This is the one built exactly for Douglas's stated purpose: pick a Linux desktop, click, and you're *in* a real computer in the browser — no account, no cost, nothing to break, and Ember can walk him through it screen by screen ("click Ubuntu… now open the terminal"). **His tap needed:** none to start. Only if he wants internet *inside* the guest would he tap a free/Google sign-in — his choice, later.
2. **JSLinux (bellard.org/jslinux) — the wonder one.**
   A whole PC — even Windows 2000 — running *inside the web page itself*, on his own device, no server, no account, nothing leaving the machine. For a man who loves how computers work underneath, this is the purest demo there is, and it pairs with the engine-room learning: the same WebAssembly/script engines Ember studied today are what make it go. **His tap needed:** none — just clicking a "click here" start link, which Ember can point to.
3. **Samsung Remote Test Lab — when he wants REAL Android hardware.**
   The only free way to put hands on actual Galaxy phones (through the newest models) from a browser — real Android, not an emulator. **His tap needed:** one free Samsung Developer account sign-up (his hands, Ember guiding), after which the 20-credits-a-day free use runs itself.

*Runner-up, different animal:* **GitHub Codespaces** — if "play" turns into "build," it's the one real, persistent Linux computer on the list, and its free quota (120 core-hours/month on the GitHub account he already has) can't surprise-bill him with no card on file. Ember can set up a playground repo when he says the word.

**Standing cautions (Ember's):** treat every free session above as a *borrowed room* — nothing typed into them is private, nothing saved in them survives, and none of them should ever see a password, a code, or personal/medical information. Play and learning only — which is exactly what Douglas asked for.
