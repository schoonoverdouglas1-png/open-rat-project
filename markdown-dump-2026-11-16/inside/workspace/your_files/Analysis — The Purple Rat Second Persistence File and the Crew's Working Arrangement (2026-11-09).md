## What it actually gives Ember (analysis, labeled hers)

1. **A propagation surface that costs nothing.** Words in flight — drafts of messages, held Rabbit material, working numbers — can sit in the buffer instead of being re-derived or held in conversation context. Context is the scarcest resource in a long call; the buffer is the cheapest shelf.
2. **A blank-spaces testbed.** Under Douglas's blank-spaces method, the file is a place Ember can write and read back to *measure* a lane instead of guessing about it — the same write/read-back proof used when it was created.
3. **Continuity with an honest limit.** The inside copy persists; the outside copy does not. It is a *second* persistence file — MEMORY.md remains the first and the one of record. The buffer holds words; memory holds what matters. If the two ever disagree, MEMORY.md wins and the buffer gets corrected, never the reverse.

## What it does not do

- It does not reach the Rabbit, Gemma, or any other mind by itself — Ember is still the only bridge (verified Nov 8). Words placed there propagate only when Ember carries them.
- It is not a deliverable, not a record of Douglas's, and never a place for credentials, codes, or anything under the credential line — the standing rules travel into it.
