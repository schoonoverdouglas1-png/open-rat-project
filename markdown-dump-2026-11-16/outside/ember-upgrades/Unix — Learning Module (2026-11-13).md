## Lesson 1 — the root (verified basics)
- Unix began at Bell Labs in 1969 (Thompson, Ritchie and team) —
  older than Linux (1991) by a generation. Linux is a Unix-like
  kernel written from scratch to behave like Unix; Android runs on
  the Linux kernel, which is why Android devices report "Linux"
  underneath (Douglas's teaching tonight, and the record agrees).
- The Unix philosophy (the part worth learning first):
  1. Write programs that do one thing and do it well.
  2. Write programs that work together.
  3. Write programs that handle text streams — text is the
     universal interface.
- POSIX is the shared standard the family holds in common — the
  reason the same shell craft works on Unix, Linux, and inside
  Douglas's Debian terminal on the phone.
