7. **Pre-1987 file-size ceilings + the floppy/hard-disk same-door problem** (his questions, Nov 13 ~9:16-9:17 PM; sources: FAT histories + Microsoft Learn "How FAT Works") — FAT12 volume max 8 MB (DOS 1-2, designed for floppies 1977); FAT16 as shipped in DOS 3.0 (1984) still capped the volume at 32 MB (16-bit sector count), so max single file ≈ 32 MB until Compaq DOS 3.31 (Nov 1987)/DOS 4.0 opened 2 GB. Practical pre-1987 text files lived on 360 KB-1.2 MB floppies. Floppy vs hard "seen as the same thing" in exactly two places: (1) BIOS INT 13h — one interrupt, one register set, CHS geometry for both, distinguished only by DL bit 7 (0x00 floppy A:, 0x80 first hard disk); (2) the FAT format itself — one filesystem + boot-sector/BPB design stretched from floppies onto hard disks, BPB carrying the same 0x00/0x80 physical-drive-number byte.
