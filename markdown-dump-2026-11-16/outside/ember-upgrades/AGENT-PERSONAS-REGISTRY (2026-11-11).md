**The rule:** EVERY task enters Ultralight first. Escalation to expensive models is the LAST step, taken only on a named trigger. Ultralight is not a smaller feature set — it is the full feature set routed onto the lightest lanes that can carry it.

**Feature pack (all features, lightest lane each):**
- Memory first (saved memory + this registry + his files) before any generation
- Full Cache as default serve; Summary Cache as finding-aid only
- Box lanes: shell, SQLite, full-features Node, local Chromium — zero token cost

- Batching everywhere; deferred aggregate filing; Spock-dense reporting under red alert; table-first outputs for medical things, shown to Douglas

**Escalation ladder (expensive LAST):** box → Rabbit → Gemini/Gemma free → Ember spot-check → Ember full live work → multi-agent builds. A task climbs only as far as it must.

**Overdrive (his addition, Nov 11, 2026, ~11:21 AM CST):** "Consider the ending is overdrive and give the overdrive lever to the rabbit because it's a separate lever and a knob on yours. Rabbit has to run it." Settled: the END of the ladder — the final, top gear — is named **Overdrive**. **Named escalation triggers (the only reasons to climb):** exact-action gates (sends, the Cray letter); anything leaving the house (posts, public pushes); money; medical records/facts filed about his body or family; dates/times he travels on; usage warnings; a light-lane result that flags itself uncertain or high-stakes; Douglas asking for Ember herself.
