## UBCD4Win — the Windows sibling (ubcd4win.com, discontinued)
BartPE/WinPE-based UBCD for Windows: versions on record include 2.5, 2.55, 2.60, and 3.00 (forum). Requires a Windows install source to build. Discontinued; the DOS/Linux UBCD above is the living line (in hibernation).

## The rest of the kind — bootable utility discs and their kin
- **Hiren's BootCD** — the other legend; original development ceased 2012 (last widely-known 15.2). **Hiren's BootCD PE** — community WinPE revival, free, current.
- **FalconFour's Ultimate Boot CD** — Hiren-based remix.
- **MediCat USB** — modern successor spirit: a big Ventoy-based USB toolkit, free.
- **Sergei Strelec WinPE** — Windows PE rescue environment, free (donation-supported).
- **DLC Boot / DLC Utilities** — WinPE utility disc, free.
- **Gandalf's Windows PE** — WinPE builds (free and supporter editions).
- **SystemRescue** (formerly SystemRescueCd) — Arch-based Linux rescue, free, actively maintained.
- **Rescatux** — Debian-based rescue with the Rescapp guide, free.
- **Trinity Rescue Kit** — Linux rescue, free, older.
- **Clonezilla** — cloning/imaging live disc, free.
- **Grml** and **Finnix** — small Debian-based sysadmin live systems, free.
- **Super Grub2 Disk** and **Boot-Repair-Disk** — boot repair specialists, free.
- **Kaspersky Rescue Disk** — antivirus rescue, free; note: since Sept 2024 US rules prohibit Kaspersky updates for US persons (borecraft), so treat its definitions as frozen in the US.
- **Anvi Rescue Disk** — free, older. **Active@ Boot Disk** — commercial. **AOMEI PE Builder** — free PE builder. **Ikki Boot** — multiboot compilation.
- **Carriers, not discs:** Ventoy and YUMI build one USB that boots many of the above; DriveDroid boots ISOs from an Android phone.
Downloads: none pulled yet — these are large; pulling the set onto the 1 TB thumb drive waits for Douglas's word on which ones.
