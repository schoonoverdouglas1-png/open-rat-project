# The Two Words, Every Way

This file is one of a set made Nov 16, 2026, at Douglas's order: the same inside in every copy, different only in the name it wears — space, dash, period, and no separator at all, for both of the two-word names he chose.

The point of the experiment, in his framing: a file's name is a label; the work inside is the thing itself. Ember's code finds files by their names and extensions in their right places — so every way of writing the name must lead to the same truth inside.
