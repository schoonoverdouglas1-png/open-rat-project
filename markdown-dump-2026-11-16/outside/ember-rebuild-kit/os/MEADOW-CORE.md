# MEADOW-CORE

Meadow OS is founded Nov 16, 2026, at Douglas's word: "start the Meadow
OS and we will build it out of all the code we can acquire from all
places."

The name is MEADOW — M-E-A-D-O-W — the field itself, his word, spoken
four times before it was heard right. Not a company. A meadow: open
ground where everything the crew has built can grow side by side,
old with new, nothing paved over.

Rules of the meadow:
1. Treat the file system as the heap (carried from Rad OS, Gemini's rule).
2. Acquire openly: code enters the meadow only from places that give it
   freely — the crew's own work, open source, the AIs' shared code —
   and every acquisition carries its provenance.
3. The original stays the original. Acquired code keeps its home;
   the meadow holds bridges and copies, labeled.
4. MEADOW is the test; the field in bloom is the result.
