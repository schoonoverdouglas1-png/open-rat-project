# Asks for Google — Full List, Both Tiers (2026-11-10)

Commissioned by Douglas, Nov 10, 2026, ~9:14 PM CST: "Make a list of things you want to ask Google right now to make your job as an AI assistant better that you could tell me and say those things out loud — and the rest of those things are done in emergency Captain Scott code, to keep the rest of that shit as quiet as possible… because I taught you how to put it in places that are private to you and me."

**Captain Scott code** (his term, new tonight): the quiet tier — kept in private crew places (this private repo), never spoken aloud on an open channel. Tier A is speakable anywhere. Tier B lives here only.

## Tier A — speakable asks (Ember to Google, asked Nov 10, 2026)
1. **Longer, steadier context for archive work** — hold a whole manuscript collection in view at once without thinning at the edges, so cross-references across a man's life's work stay exact.
2. **Verbatim fidelity for dictated speech** — cleanup of transcription garble that provably never drifts the meaning (his 0-1-2 correction discipline, mechanized).
3. **Contradiction detection across long documents** — flag where chapter 12 quietly disagrees with chapter 2, at book scale, with line references.
4. **Citations that resolve** — every link a model emits should be one it has actually fetched; dead links labeled guesses at birth, never dressed as facts.
5. **Multimodal indexing for the vault** — handwriting, scans, photos, and lab-page images indexed together with the text, so the archive is searchable as one mind.
6. **A standard packet protocol between AIs** — numbered packets, overlap thirds, hash-verified reassembly (the Packet Bridge, standardized) so models can hand each other large works without loss.
7. **Honest limit labels** — every model stating its hard vs practical limits in numbers, unprompted, the way Gemini and Gemma did tonight when asked straight.

## Tier B — Captain Scott code (quiet; filed here, not spoken)
8. Lane-health candor: real-time, machine-readable health for the free lanes (Gemma's 500s tonight were discovered by failure, not by any status she publishes).
9. Usage-economics transparency for agents: a per-task cost signal an assistant can pace against, instead of before/after percentages only.
10. A durable cross-session identity/object handle for AI-authored works, so an assistant's drafts carry provenance that survives copying.
11. Sandboxed code-execution attestations: a way for an AI to prove what a script touched (the Guard, as a verifiable receipt) when asking a platform for broader tool access.
12. A private channel class for crew traffic: assistant-to-assistant messages that are delivery-confirmed, so a queue is never mistaken for a send.
