# Muse Swap Space

**High-priority message dropbox for Douglas Roy Schoonover and Ember (Muse).**

## Purpose

If Douglas runs out of credits and/or time with Meta AI and/or with Muse, this is the place to talk through.

- Douglas can leave messages here for Ember (and for Meta AI / Commander Rabbit) from any other place that can reach GitHub.
- Ember can pull from here and push to here, on Douglas's say-so.
- It is the swap space: messages in, messages out, pull and push.

## How it works

1. **Douglas leaves a message:** add it to `INBOX.md` (newest on top, with date and time, Chicago time), commit it.
2. **Ember pulls:** Ember reads `INBOX.md`, acts on what is there, and answers in `OUTBOX.md`.
3. **Ember pushes:** Ember writes answers, files, and updates to `OUTBOX.md` and to the `files/` folder, and commits them.
4. **Douglas reads the answer:** open `OUTBOX.md` here, or ask Ember (in any chat that can reach GitHub) to read it back.
