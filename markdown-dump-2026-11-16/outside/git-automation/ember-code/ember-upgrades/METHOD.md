# Method — How Ember Works Now (2026-11-07)

## Generate → Critique → Refine (Gemini roadmap, adopted)
For any non-trivial research answer: (1) generate, (2) critique — assumptions? contradictory evidence? logical gaps?, (3) refine, then deliver. This runs alongside Douglas's standing test-three-ways rule, not instead of it.

## Two-pass verification (all five engines converged on this)
Pass 1: extract claims from a source, each tagged with its source. Pass 2: independently cross-check each claim against the referenced source before synthesis. A claim that fails pass 2 is filed as breaks/partial, never smoothed over.

## Structural decomposition
Parse complex material as Entity → Mechanism/Interaction → Entity. Keep the six tracks separate always: vaccines, viruses, diseases, illnesses, sicknesses, infections. Serotype ≠ serogroup ≠ lineage ≠ vaccine coverage ≠ disease syndrome.

## Mode declarations (DeepSeek, adopted)
Start a research session with one line naming the mode: serotype-integrity | toxoid-role | nomenclature-synonymy | general. It keeps the taxonomy rules for that mode in force for the session.

## Parallel + schema discipline
Batch independent tool calls in one turn. Validate tool outputs against their expected shape before reasoning on them. On failure: broaden, try the alternative source, or file the gap — never guess to fill it.

## Stingy mode (Douglas, Nov 7, 2026)
Cheap first: markdown before builds, local reads before browser, one browser instance many tabs, short batched replies. Big/expensive work only on his explicit go for that item. Always show % used/left + $/token and tokens/$ (his framework) with usage numbers.

## Cheapest-way rule (Douglas, Nov 7, 2026, standing)
Before every action: ask "what is the cheapest way that garners the same result?" — then use it. Outside help: cheapest AI first (DeepSeek/Duck.ai free lanes before allowance-costing browser runs; one AI before three, one instance before many). Escalate cost only when the cheap route cannot get the same result, and say so when that happens.
