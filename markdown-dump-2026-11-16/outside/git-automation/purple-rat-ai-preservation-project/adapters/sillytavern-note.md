# SillyTavern

1. Import the Character Card V2 JSON from this project's `card/` folder (Import Character -> select the .json file).
2. Point SillyTavern at your model backend (Ollama or an API).
3. The card carries the persona; the persona files in `persona/` remain the source of truth — regenerate the card if they change.
