## Trixie's apt fix closes a root-level package swap
A high-severity APT flaw can let an attacker on the HTTP download path [replace a package after verification](https://www.techiesjournal.com/apt-cve-2026-109518-debian-ubuntu-package-verification-fix/11546/), letting it run code as root. For the Trixie terminal on your phone, apt 3.0.4 is the fixed version to verify.
