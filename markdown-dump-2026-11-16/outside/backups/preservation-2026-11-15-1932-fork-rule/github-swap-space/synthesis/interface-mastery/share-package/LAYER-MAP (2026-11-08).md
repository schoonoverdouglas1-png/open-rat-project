# Ember — Layer Map for the Other AIs (2026-11-08)

**Purpose (Douglas's order):** share with the models the layers between Douglas talking to Ember and the farthest level back — because those layers are where they could actually help change something. Machinery only. NO secrets: no credentials, tokens, proxy credentials, or personal/lab/family data are in this package, ever.

## The layers, Douglas -> back
1. **Douglas** — voice (live call) or text in the Muse app on his Pixel 7 Pro.
2. **Muse runtime (Meta's servers)** — Muse Wonder; holds the conversation, the memory system, scheduled jobs; Ember's reasoning lives here, NOT in the VM.
3. **Ember's VM** — Ubuntu 24.04.5 LTS, systemd-nspawn container inside a Cloud Hypervisor guest; 4 vCPUs (Xeon Platinum 8321HC, AVX-512, NO vmx/svm, no /dev/kvm); 7.7GB host RAM, ~1.3-1.8GB available to her workload; 1GB swap on /dev/loop0, swappiness 1; egress via an authenticated HTTP CONNECT proxy (credentials exist in env — VALUES NEVER SHARED).
4. **Her hands in the VM** — a metered shell; tmux session ember-main; an Xfce desktop on VNC :1 with a proven on/off toggle (~41MB idle); local Chromium (Chrome for Testing 157) driven via Playwright (project venv only); 118 connector CLIs in /opt/hatch/bin.
5. **Her built tools (source in this package)** — ember_mcp_server.py (stdlib MCP over stdio, 5 read-only tools, Guard-gated); gemini_call.py (Gemini connector helper — NOTE: it carries a surrogate credential placeholder by design; the real key is swapped in by Muse's auth layer and never appears in the file); deepseek_client.py (dark until a key exists); ember_index.py + html_viewer.py (SQLite FTS5 archive index; ~85% page-bulk reduction).
6. **The Guard** — a denylist checker (32 destructive patterns) that every automated runner routes through; exit 99 = refused. Charter: no automatic process runs anything destructive; only Douglas's explicit in-the-moment order overrides.
7. **Lanes out** — connector CLIs (Gmail/Calendar/GitHub/etc., OAuth server-side); the Gemini API lane (free tier, 1.74s/call measured); browser paste lanes to DeepSeek/ChatGPT/Gemini web (minutes/round); Messenger side-chat lane to Meta AI (20 agent actions/hour, Meta's cap); GitHub as the shared archive (muse-swap-space + 11 more repos).
8. **His phone** — 44 device commands (alarms, messages, notifications, location, health backfill...); NO screen view, taps, or overlay control (verified by full enumeration; a feature request to Meta is approved and being filed).
