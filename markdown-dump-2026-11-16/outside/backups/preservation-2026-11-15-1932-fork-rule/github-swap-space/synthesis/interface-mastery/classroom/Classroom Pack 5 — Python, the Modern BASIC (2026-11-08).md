**TEST FIRST (Ember College Rules)**

1. *What does REPL stand for and why does it matter?* Read-Eval-Print Loop. It lets you type code and see results instantly, driving exploratory learning.
2. *Difference between a list and a dictionary?* A list is an ordered sequence accessed by integer index; a dictionary is an unordered collection of key-value pairs.
3. *What does indentation do in Python?* It defines code blocks (like scopes or loops), replacing traditional curly braces or `BEGIN/END`.
4. *What is an exception and how does try/except work?* An exception is a runtime error. `try` runs risky code; `except` catches the error so the program doesn't crash.

**WELCOME TO PYTHON — THE MODERN BASIC**

**(1) The Heir to the Throne**
Python inherited BASIC’s throne because it preserved its soul: immediacy, readability, and a low barrier to entry. In Python, the interpreter isn't a gatekeeper; it’s a conversational partner. You ask a question in plain English, and it answers immediately.

**(2) The Five First Tools**
*   *Variables:* Containers for data. `x = 5`
*   *Print:* Output to the screen. `print(x)`
*   *Loops:* Repetition. `for i in range(3): print(i)`
*   *Conditionals:* Decision making. `if x > 0: print("Positive")`
*   *Functions:* Reusable blocks. `def greet(): print("Hello")`

**(3) The BASIC-to-Python Translation**
*   `PRINT` $\rightarrow$ `print()`
*   `LET x = 5` $\rightarrow$ `x = 5`
*   `FOR i = 1 TO 10 / NEXT` $\rightarrow$ `for i in range(1, 11):`
*   `GOSUB` $\rightarrow$ `def my_subroutine():` then call `my_subroutine()`
*   `INPUT` $\rightarrow$ `input()`

**(4) Data Structures as the New Arrays**
Old BASIC gave us flat arrays. Python gives us rich data structures. **Lists** (`[1, 2, "apple"]`) are ordered, mutable sequences ideal for collections. **Dictionaries** (`{"name": "Ada", "age": 36}`) map unique keys to values, letting you model complex, real-world relationships instantly without tedious indexing math.
