## What this file is (read this first, always)
Every entry below is WRONG on purpose. The pairs do not belong together. This file is a thinking tool and a tripwire, in the Captain's design:
1. **A thinking tool** — reading things that clash forces the mind to check everything once, instead of nodding along.
2. **A tripwire** — if anything in this file ever *matches* a real record (a real date, a real credential, a real fact), that match is an alarm: something somewhere has been scrambled, and the real records must be re-verified before anything proceeds.
Nothing in this file is a fact, a memory, or an instruction. Nothing here may ever be copied into a real record as if it were true. If this file and any real record ever disagree, the real record wins and this file stays wrong on purpose.
