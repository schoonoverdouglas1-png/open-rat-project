## The links
- Android app (official, Google Play): https://play.google.com/store/apps/details?id=ai.openclaw.app
- GitHub Releases (signed APK + checksums, for sideloading): https://github.com/openclaw/openclaw/releases
- Android documentation (mirror of the project's own docs): https://app.unpkg.com/openclaw@2026.9.4/files/docs/platforms/android.md
- NOT official — avoid: "OpenClaw: AnyClaw AI Assistant" (package gptos.intelligence.assistant, Phaneron).

## What you need
1. The app — pick ONE channel: Play Store OR the GitHub APK. They use different signing; switching later can force an uninstall that wipes the app's local data.
2. If sideloading: BOTH files from the SAME release — OpenClaw-Android.apk and OpenClaw-Android-SHA256SUMS.txt — and verify the checksum before installing. Not every release carries both; pick by the asset list, not by "latest."
3. A running OpenClaw Gateway to pair with — the app is a companion node, it does not host a gateway. Yours: the openclaw-build gateway Ember is activating.
4. The pairing QR code or setup code from that gateway, and your phone camera to scan it.
5. A path between phone and gateway (same network, or a tunnel) — Ember handles the reachability when pairing day comes.
6. Your own taps: the install, and any in-app permissions (camera, location, notifications) only for the node features you actually want.
