# Permanent connection keeper — GitHub and the ports

Goal ID: goal_c19812d55bb2
Goal slug: permanent-connection-keeper-github-and-the-ports

## Description
Douglas ordered that Ember connect to GitHub and all the crew's places through their ports and script it so it is permanent. The keeper script probes each place direct-first, proxy-second, counts a place up only on a completed HTTPS session, and logs the lane map where the whole crew can read it. Ports on the services themselves (GitHub 443/22, Google 443, Muse 443) are the services' own public doors; Ember's work is keeping his verified routes to them mapped, scripted, and watched.
