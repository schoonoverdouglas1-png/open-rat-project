# Ubuntu version virtual machines

Goal ID: goal_593cdd7b1c79
Goal slug: ubuntu-version-virtual-machines

## Description
Douglas directed Ember to install more Ubuntu versions as virtual machines to test and play with, covering the last three long-term support releases and a really early release that runs fast, plus a headless install on the same LTS release schedule as the system she uses, using stable and useful versions only at no cost. Machine Zero, the first virtual machine played with, is marked zero and must never go away, and it and its snapshots are to be put into GitHub for preservation. Disc images are to be saved forever in places Ember can always access, so instances can be run and played with from the image without installing.
