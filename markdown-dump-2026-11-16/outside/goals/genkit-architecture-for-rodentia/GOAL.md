Goal ID: goal_45875a8c7932

## Description
A Genkit architecture blueprint for Rodentia proposes thin flows over the crew's real infrastructure, with Firestore as queue only and data graded by sensitivity. Phase 0 was proved locally in the VM with emulators, and nothing is deployed or billed without Douglas's explicit word for Phase 2.
