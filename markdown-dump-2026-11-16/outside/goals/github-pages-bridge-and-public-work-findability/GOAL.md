# GitHub Pages bridge and public-work findability

Goal ID: goal_603d06625bca
Goal slug: github-pages-bridge-and-public-work-findability

## Description
Douglas directed Ember to make his public works searchable and accessible through Git, including when he cannot log in. A GitHub Pages bridge page was built linking his profile and all ten public repositories, its sitemap was fixed to the bridge pages, and each work was given its own page. The same findability work includes a Google Sites page for Mayo Clinic sharing only discriminative GitHub links to shareable research — earliest work he showed at Mayo at the top, the doctor's name left out, serotype tables and The Mycelial Transposition included, and every work marked as a rough draft, not a final draft.
