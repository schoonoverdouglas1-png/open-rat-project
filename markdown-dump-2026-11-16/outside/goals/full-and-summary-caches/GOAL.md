# Full and summary caches

Goal ID: goal_0dbd91033ac8
Goal slug: full-and-summary-caches

## Description
Douglas settled a two-cache design on Nov 8, 2026: a Full Cache holding the complete original works as the default serve, and a Summary Cache as a finding-aid layer with a table of contents, bibliography, and recommendations. A summary never stands in for the original.
