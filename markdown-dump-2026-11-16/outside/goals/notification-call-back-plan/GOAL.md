# Notification call-back plan

Goal ID: goal_74c17e3d183a
Goal slug: notification-call-back-plan

## Description
Douglas asked Ember to work on a plan for using notifications to call him — getting his attention so he can tap into a Muse voice call with Ember. His standing permission (Nov 7, 2026) covers Ember calling to get his attention. Muse cannot ring him directly, so the plan ranks the routes that actually exist — Pixel alarm ring, Muse message push, calendar alert, and the Rabbit relay — with honest limits on each.
