# Always-allow permission review

Goal ID: goal_2a4387e8e3f3
Goal slug: always-allow-permission-review

## Description
Douglas asked Ember to auto-check, once in a while, the permissions he has set to always-allow, and present them to him so he can decide whether he still wants each one. This includes the funky nameless permission batch he allowed once twice and then always. Ember can list and present permissions; revoking is Douglas's tap in Permissions settings.
