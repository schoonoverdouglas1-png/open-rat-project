# Rad OS

A universal operating system that runs off the reading and writing of files.
Markdown first; txt, json, xml and csv beside it.

Commissioned by Douglas Roy Schoonover, Nov 16, 2026.
Kernel by Ember. `programs/null_thought` by Gemini.
**RAD is the test. RAT is the result.**

## Run it
- `python3 rados.py boot` — boot from system/BOOT.md, write system/state.json
- `python3 rados.py run <program>` — run a program out of programs/
- `python3 rados.py read <datafile>` — read a txt/csv/xml data file out of system/
- `python3 rados.py test` — run tests/RAD.md, write tests/RAT.md

## File kinds at work
- `.md` — boot file, programs, tests, results
- `.json` — config, state, program directives
- `.txt` — plain data
- `.csv` — tables
- `.xml` — settings
