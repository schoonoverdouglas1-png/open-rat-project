# How to Pull and Push from the Muse Swap Space

## For Douglas

- **Leave a message:** open `INBOX.md` on GitHub, tap Edit (pencil), add your message at the top with the date and time, tap Commit changes.
- **Read Ember's answer:** open `OUTBOX.md` here on GitHub.
- **From another AI:** paste this repo link — https://github.com/schoonoverdouglas1-png/muse-swap-space — and tell that AI: "Read INBOX.md and OUTBOX.md in this repo, and leave my message in INBOX.md." Then tell Ember (in any Muse chat) to pull from the swap space.
- **Tell Ember to pull:** "Ember, pull from the muse swap space." She reads INBOX.md and acts on it.
- **Tell Ember to push:** "Ember, push to the muse swap space." She writes her answer to OUTBOX.md (and files to `files/`), and commits it.

## For Ember (Muse)

- **Pull:** read `INBOX.md` from `schoonoverdouglas1-png/muse-swap-space` (main branch) via the GitHub connector. Act on the newest message first, then the older ones. Never delete an old message.
- **Push:** write the answer to `OUTBOX.md` (newest on top, dated, Chicago time) via the GitHub connector, and push any files to `files/`. Read the result back to verify it landed.
- **If credits/time run out mid-task:** leave a note in OUTBOX.md saying where the work stopped, so Douglas (or another AI) can pick it up from there.
- **If the repo is not in the GitHub App installation yet:** ask Douglas to open the Select repositories link and choose `muse-swap-space`, then verify access with a read before pushing.

## For Commander Rabbit (Meta AI, via Ember)

- Rabbit does not reach GitHub directly. Ember is the bridge: Ember reads INBOX.md to Rabbit in Messenger, and writes Rabbit's answers into OUTBOX.md, labeled as Rabbit's.
- Rabbit's standing rules still hold: suggestions always, senior staff reporting to Ember, Number One is Ember.

## What never goes here

No passwords, no codes, no IDs, no full lab PDFs (DOB/MRN), no Cara material.
