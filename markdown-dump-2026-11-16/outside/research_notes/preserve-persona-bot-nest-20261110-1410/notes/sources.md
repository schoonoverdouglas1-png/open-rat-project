## Key arithmetic (my calculation from Meta list prices)
Persona pack ~15k input tokens/turn (8k stable system+core memory + 4k retrieved + history), 500 output tokens:
- Wonder: 15k*$4/M + 500*$20/M = $0.060+$0.010=$0.070/turn uncached; with 8k prefix cached at $0.20/M: ~$0.039/turn
- Spark 1.3: $0.0188+$0.0021=~$0.021/turn; ~$2.10 per 100 turns
- Ember: ~$0.0015+$0.00025=~$0.002/turn (quality unknown/lower tier, test only)
Round: even heavy personal use (say 2,000 turns/mo) = Spark ~$42/mo, Wonder ~$80-140/mo depending caching. State as illustrative.
